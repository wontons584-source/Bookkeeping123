# 大学生生活费记账分析系统（life-ledger）

**双击 index.html 即可使用**（Chrome / Edge 浏览器，file:// 协议直开，无需启动任何服务、零网络请求）。

## 功能一览

### 账号与数据隔离（v2 新增）

- 注册 / 登录 / 登出：用户名 + 密码 + 角色（学生 / 家长，注册后不可改），同一浏览器可并存多个账号
- 登录态存 sessionStorage：刷新保持登录，关闭浏览器即退出
- 数据按账号隔离（per-user 键 `ledger_v2:{用户名}:bills` / `:accounts`），互不可见
- 密码只存 SHA-256 哈希，任何情况下不落明文（课程演示用途，非生产级安全）
- v1 旧数据自动迁移：**首个学生账号注册成功**时触发一次，先写后删，失败保留旧键可重试

### 角色分流（v2 新增）

- 学生：完整记账 / 分析 / 账户功能 + 邀请码绑定管理
- 家长（未绑定）：绑定引导页，输入孩子的 6 位数字邀请码完成绑定
- 家长（已绑定）：只读视图实时查看孩子当月饼图、AI 洞察、总资产；DOM 中无任何录入/删除/修改入口
- 邀请码一次性使用：绑定成功即失效；重新生成旧码作废；解绑不恢复码；一对一绑定

### 记账与分析（v1 沿用）

- 手动录入账单：日期 / 金额（元）/ 商户（可空）/ 分类（餐饮·交通·学习·娱乐·日用·其他）/ 刚性·冲动标签 / 备注（可空）
- 全部历史账单列表，删除前有 confirm 确认
- 本月统计（饼图 + AI 消费洞察）：只统计当前自然月（拍板 A1），历史账单保留在列表但不参与统计
- 多账户（微信 / 支付宝 / 现金 / 自定义）余额手动维护，总资产自动汇总（拍板 B1：与账单完全解耦）
- 金额一律以"分"为整数单位存储，全链路无浮点

### 端侧 AI 三件套（全部本地规则引擎，零网络请求）

- **语音记账**（v1 保留）：识别结果只预填表单，确认后才保存
- **智能分类推荐**（v2 新增）：商户/备注键入时实时匹配 ≥40 词条中文词典，出"分类 + 刚性/冲动"推荐卡（理由含命中关键词），可采纳或忽略；语音预填后同走推荐；推荐只动表单，永不直接落库
- **AI 消费洞察**（v2 升级，替代 v1 固定 3 条建议）：11 个模板按五类组织（结构/对比/习惯/风险/资产），带触发条件与相关度排序，每次 2–4 条；当月不满 3 笔输出解锁引导话术；对比类需要上月数据

## 语音记账说明（如实披露）

语音用的是浏览器内置 Web Speech API（`webkitSpeechRecognition`，`lang='zh-CN'`）。
该 API 在 file:// 协议下的可用性随浏览器版本与权限策略而异：

- 若点"语音记账"提示"当前环境不支持语音记账，请手动填写"，属于预期内的降级路径，其余功能全部不受影响；
- 想启用语音可在项目目录起一个本地静态服务后再访问：
  ```
  python -m http.server 8000
  ```
  然后浏览器打开 `http://localhost:8000`；
- 兜底：无论语音是否可用，手动输入始终可用，记账主流程不会被语音失败挡住。

## 运行自动化测试

需 Node ≥ 18，在项目根目录逐条执行：

```
node test/stats.test.js       # 统计纯函数（金额分精度/分类汇总/环比/上月前缀）
node test/qa-extra.test.js    # 边界探测（脏入参容错/极大金额/无存储环境/语音解析）
node test/recommend.test.js   # 智能分类推荐（词典命中/null/取首个/理由含命中词）
node test/insights.test.js    # AI 洞察（触发边界/条数[2,4]/引导话术/整数分口径）
node test/auth.test.js        # 认证（哈希确定性/注册校验/邀请码查重/迁移决策三态）
```

统计与认证模块均为 UMD 双环境导出，浏览器交互（登录注册、confirm、饼图渲染、推荐卡）靠下方手动验收清单覆盖。

## 目录结构

```
life-ledger/
├── index.html          # 唯一页面入口（主容器 #app-main 由 app.js 按角色整体渲染）
├── css/style.css       # 样式
├── js/app.js           # 页面渲染与事件绑定（唯一 DOM 操作入口；登录/注册/角色分流/推荐卡/洞察区）
├── js/store.js         # localStorage / sessionStorage 读写与校验（唯一允许碰存储的文件；per-user 键与迁移）
├── js/stats.js         # 统计计算（纯函数；v1 固定建议规则已移除，补充环比所需函数）
├── js/speech.js        # 语音识别（含可用性检测与降级提示）
├── js/auth.js          # 注册/登录校验、SHA-256 哈希、会话、邀请码、迁移决策（纯逻辑，不碰存储）
├── js/recommend.js     # 智能分类推荐词典与匹配（纯函数）
├── js/insights.js      # AI 消费洞察模板库与生成器（纯函数，依赖 stats）
├── lib/chart.js        # Chart.js v4.4.1 UMD 本地文件（禁止 CDN 外链）
├── test/*.test.js      # 5 个 Node 原生 assert 断言脚本
└── README.md
```

- 脚本以经典 `<script src>` 按依赖顺序引入（file:// 下 ES modules 会被 CORS 拦截）
- 无构建工具、无 npm 依赖、无任何网络请求
- 存储键：`schema_version` / `ledger_v2:users` / `ledger_v2:{用户名}:bills` / `ledger_v2:{用户名}:accounts`（localStorage）；`ledger_v2:session`（sessionStorage）；v1 旧键 `bills` / `accounts` 仅存在于迁移逻辑中
