# 大学生生活费记账分析系统（life-ledger）

**双击 index.html 即可使用**（Chrome / Edge 浏览器，file:// 协议直开，无需启动任何服务、无需注册登录）。

## 功能一览

- 手动录入账单：日期 / 金额（元） / 商户（可空） / 分类（餐饮·交通·学习·娱乐·日用·其他） / 刚性·冲动标签 / 备注（可空）
- 全部历史账单列表，删除前有 confirm 确认
- 本月统计（饼图 + 消费分析省钱建议）：只统计当前自然月（拍板 A1），历史账单保留在列表但不参与统计
- 语音口述记账：识别结果只预填表单，确认后才保存
- 多账户（微信 / 支付宝 / 现金 / 自定义）余额手动维护，总资产自动汇总（拍板 B1：与账单完全解耦）
- 数据全部存本机浏览器 localStorage（键：`schema_version` / `bills` / `accounts`），金额以"分"为整数单位存储

## 语音记账说明（如实披露）

语音用的是浏览器内置 Web Speech API（`webkitSpeechRecognition`，`lang='zh-CN'`）。
该 API 在 file:// 协议下的可用性随浏览器版本与权限策略而异：

- 若点"语音记账"提示"当前环境不支持语音记账，请手动填写"，属于预期内的降级路径，其余功能全部不受影响；
- 想启用语音可在项目目录起一个本地静态服务后再访问：
  ```
  python -m http.server 8000
  ```
  然后浏览器打开 `http://localhost:8000`；
- 兜底：无论语音是否可用，手动输入始终可用，记账主流程不会被语音失败挡住。

## 运行自动化测试

需 Node ≥ 18，在项目根目录执行：

```
node test/stats.test.js
```

只测统计纯函数模块（js/stats.js，UMD 双环境导出），浏览器交互（语音唤起、confirm、饼图渲染）靠下方手动验收清单覆盖。

## 目录结构

```
life-ledger/
├── index.html          # 唯一页面入口
├── css/style.css       # 样式
├── js/app.js           # 页面渲染与事件绑定（唯一 DOM 操作入口）
├── js/store.js         # localStorage 读写与校验（唯一允许碰存储的文件）
├── js/stats.js         # 统计计算与建议规则（纯函数，不碰 DOM 和存储）
├── js/speech.js        # 语音识别（含可用性检测与降级提示）
├── lib/chart.js        # Chart.js v4.4.1 UMD 本地文件（禁止 CDN 外链）
├── test/stats.test.js  # Node 原生 assert 断言脚本
└── README.md
```

- 脚本以经典 `<script src>` 按依赖顺序引入（file:// 下 ES modules 会被 CORS 拦截）
- 无构建工具、无 npm 依赖、无任何网络请求
